Structura View on GitHub

A workbench for studying the Hebrew Bible, Septuagint, and Greek New Testament. Loaded with morphological data and a layered annotation system for linguistic, narrative, and discourse analysis.

Features

Structure your study of the biblical text

Structura combines tools for reading, translating, annotating, and analyzing biblical texts in a single desktop application — available on macOS, Windows, and Linux.

📖

Reading & Display

Three display modes — Clean, Color-coded morphology with custom rules per part of speech, and Interlinear (lemma, Strong's, parsing code, constituent labels, or custom word datasets). Click any word to see grammatical information for each word, as well as a lexicon entry. Includes a side-by-side OSHB/LXX parallel view. Adjustable font sizes, full dark mode, and a customizable toolbar.

⊞

Presentation Mode

Enlarge text for screen sharing or teaching — source text scales to 2× and translation text to 3× normal size, with section headings enlarged proportionally. The Structura server runs on port 3737, so any browser on the same machine can open http://localhost:3737 while the app is running. Add ?present to a URL to open directly in Presentation Mode, or ?present&toolbar=0 for a clean, chrome-free view suitable for embedding in a Reveal.js <iframe>. The 🔗 button in the toolbar copies a ready-to-paste URL.

🔄

Translation Support

Built-in ULT (English, 31,102 verses) and VCB Vietnamese Contemporary Bible (31,096 verses) are bundled and need no setup. Import your own translation by pasting verse text or uploading USFM. Edit translation text in place — edits persist and override the built-in base text. Display multiple translations side by side with independent paragraph breaks, indentation, and formatting. Translations are shared across all workspaces.

¶

Structural Annotation

Mark paragraph breaks and apply up to five levels of indentation — source and translation indentation can be linked or controlled independently. Apply bold and italic per word. Define scene and episode breaks across a six-level hierarchy with headings, out-of-sequence flags, and optional thematic letter labels (A–Z). View and export the full outline with a collapsible sidebar.

→

Discourse Analysis

Draw RST (Rhetorical Structure Theory) relation arrows between paragraph segments using 15 relation types — Cause/Reason, Purpose, Concession, Condition, Inference, Temporal, and more across coordinate and subordinate categories. Also supports free-form directional arrows between any two words across verse boundaries. Annotate lines with plot elements, theme labels (A/B/C), or free-form descriptions.

🎭

Character & Speech

Build a character cast with custom colors per book. Tag words as character references with support for dual-character tagging shown as a striped underline. Mark contiguous speech sections with 21 speech-act classifications including Command, Question, Promise, Lament, and more.

🏷

Word Tags & Bible Lookup

Tag words by lexical form in one click, or create custom named concept tags for themes and motifs. Highlight all instances of a tag across the text. The Bible Lookup pane (📖) retrieves any reference by name — thousands of translations via fetch.bible (no key required) or api.bible (NASB, NLT, NIV, KJV). Scripture tooltips appear on hover in the notes panel. Filter the translation dropdown by language.

💾

Workspaces, Passages & Export

Multiple workspaces keep annotations scoped separately while sharing imported translations. Define named passages spanning chapters and study them in a dedicated passage view with all annotation tools. Export any view to PDF or PNG. Back up the entire database manually or on a schedule with configurable retention policies. Fifty-step undo for all annotation operations.

Text Sources

Five bundled texts — no downloads needed

Structura ships with five bundled texts covering the full biblical canon in Hebrew, Greek, English, and Vietnamese — ready to use on first launch.

OSHB

Open Scriptures Hebrew Bible

Biblical Hebrew Old Testament with full morphological tagging — 305,507 words.

SBLGNT

SBL Greek New Testament

Koine Greek NT with MorphGNT morphological data — 137,554 words.

LXX

Septuagint (Rahlfs 1935)

Koine Greek Old Testament with full text — 623,199 words.

ULT

UnfoldingWord Literal Text

English literal translation — 31,102 verses across all 66 books. CC BY-SA 4.0.

VCB

Vietnamese Contemporary Bible

Biblica® Open Vietnamese Contemporary Bible 2015 — 31,096 verses across all 66 books.
